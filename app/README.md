# Sheetly

Sheetly is a React + TypeScript + Vite app inside a small monorepo. The app follows
the roadmap foundation: FSD layers, Tailwind, React Router, Zod, Recharts, Vitest,
ESLint, Prettier, Husky and GitHub Actions.

## Scripts

- `npm run dev`
- `npm run typecheck`
- `npm run lint`
- `npm run format:check`
- `npm test`
- `npm run build`

Run scripts from the repository root; they proxy to the `app` workspace.
